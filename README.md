# Lovable-Ai-free-credit

Lvbl Infinity Unlimited Extension — free plans rebuild.

## Stack
- Next.js 16 + TypeScript + Tailwind
- Supabase Auth (admin only: sumitjilowa34@gmail.com)
- License key management

## Setup
1. Copy `.env.local` with Supabase URL and anon key
2. `npm install`
3. `npm run dev`

## Deploy
Connected to Vercel. Push to main deploys automatically after link.
